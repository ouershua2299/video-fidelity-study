# 视频保真度评测

盲测页面：每组展示一段参考视频和两段加速生成的视频 A、B（三段同步播放，可拖动进度条、逐帧前后移动、放大对比同一帧），
评分人判断“哪个更接近参考视频”。共 12 个对比组合（H3：SOL、SubBlock；Wan：SOL、SubBlock、SVG2、SVG-EAR；各含 T2V 和 I2V），每人从每个组合各抽 2 组，再加 2 道注意力检查题，共 26 组，约 10 分钟。

## 发起人设置（约 10 分钟）

### 1. 建收集表格（Google 表格 + Apps Script）
1. 在 Google Drive 新建一个 Google 表格，名字随意。
2. 菜单 **扩展程序 → Apps Script**，删掉编辑器里的默认代码，把本仓库 `apps_script.gs` 的全部内容粘贴进去，保存。
3. 右上角 **部署 → 新建部署**，类型选 **网页应用**：
   - 执行身份：**我**
   - 有权访问的用户：**任何人**
4. 点部署，按提示授权，复制得到的 **网页应用 URL**（形如 `https://script.google.com/macros/s/…/exec`）。
5. 打开本仓库的 `index.html`，在开头附近找到 `const ENDPOINT = '';`，把 URL 填进引号里。

### 2. 发布到 GitHub Pages
1. 在 GitHub 新建一个仓库（公开仓库才能免费使用 Pages）。
2. 把本目录推送上去：
   ```
   git remote add origin https://github.com/<用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录 `/ (root)`，保存。
4. 一两分钟后得到链接 `https://<用户名>.github.io/<仓库名>/`，发给同事即可。

### 3. 查看结果
答案会实时出现在表格的 `responses` 工作表里，每行是一个人对一组的回答。收集完后导出为 CSV 发给分析者。
如果有人提示“无法提交”，让他在页面上点 **导出结果**，把生成的 json 文件发回来，同样可以统计。

## 评分人怎么用
打开链接 → 开始。空格键播放/暂停，左右方向键逐帧移动。
中途关闭没关系，用同一个浏览器重新打开即可继续。

## 说明
- 视频文件名是随机编号，页面里不含任何方法名；方法对应表不在本仓库中。
- 每个提示词只出现一次（不同随机种子和风格变体视为同一提示词），优先选择运动和细节多的视频。
